About This Manual

This training manual is designed for organization administrators who will manage OrgVault for their company. Each module contains a real-world scenario and hands-on exercises. Complete each exercise to build proficiency.

Prerequisites: A computer with a modern browser (Chrome, Edge, Firefox, or Safari). An OrgVault account with org_admin or superadmin role.

App URL: https://storageapp.boosterappsolutions.com

MODULE 1: First-Time Setup

Scenario: You've just been given a superadmin account. You need to set up your organization, create companies for your business units, and add your first team members.

Exercise 1.1 — Create Companies

🎯 Goal: Create 3 companies for your organization.

1 Log in and click Companies in the left sidebar
2 Click "Add Company"
3 Create these companies one at a time: Alpha Division, Beta Division, Gamma Division
  • Alpha Division created
  • Beta Division created
  • Gamma Division created

Exercise 1.2 — Add Team Members

🎯 Goal: Create 4 users with different roles and company assignments.

1 Click Users in the sidebar
2 Click "Add User" and create:

Exercise 1.3 — Set Storage Quotas

🎯 Goal: Set a 20 GB org quota and per-company limits.

1 Go to Settings
2 In Storage Quota, set Organization Total to 20 GB
3 Set company quotas: Alpha → 10 GB, Beta → 5 GB, Gamma → 5 GB
  • Org quota shows 20 GB
  • Each company quota set
  • Usage bar visible and at 0%

MODULE 2: File Management

Scenario: Your team needs to store and organize business documents securely. You'll upload files, organize them with folders and tags, and verify company-scoped access.

Exercise 2.1 — Upload & Organize

🎯 Goal: Upload 3 files with folder and tag organization.

1 Go to Files
2 Upload a file to folder reports/2024 with tag confidential
3 Upload a file to folder invoices with tag billing
4 Upload a file with no folder and tag general
  • 3 files uploaded successfully
  • Folders appear in the folder grid with file counts
  • Tags visible on files

Exercise 2.2 — Navigate & Filter

🎯 Goal: Use folder breadcrumbs, tag filtering, and search.

1 Click the reports/2024 folder — verify only the reports file appears
2 Click Root in the breadcrumb to go back
3 Click the confidential tag on a file — verify filtered view
4 Use the search bar to find a file by name
  • Folder navigation works with breadcrumbs
  • Tag filter shows only matching files
  • Search returns correct results

Exercise 2.3 — Test Company Isolation

🎯 Goal: Verify that users only see their company's files.

1 As admin, switch the company dropdown to Alpha Division
2 Upload a file — it should be scoped to Alpha Division
3 Switch to Beta Division — the Alpha file should not appear
4 Switch to All Companies — both files should appear
  • Files filtered correctly per company
  • All Companies shows combined view

Exercise 2.4 — Download & Delete

🎯 Goal: Download a decrypted file and soft-delete another.

1 Hover over a file and click ⬇ Download
2 Verify the downloaded file opens correctly
3 Hover over another file and click 🗑 Delete
4 Confirm deletion — verify the file disappears from the list
  • Downloaded file is intact and readable
  • Deleted file removed from view
  • Storage usage updated after delete

MODULE 3: Data Records

Scenario: Your team tracks client contacts and invoices. You need to create structured data tables and manage records.

Exercise 3.1 — Create Tables

🎯 Goal: Create two data tables.

1 Go to Data Records
2 Click "New Table" → name it Clients → Create
3 Click "New Table" → name it Invoices → Create
  • Both tables appear in the left panel

Exercise 3.2 — CRUD Operations

🎯 Goal: Create, read, update, and delete records.

1 Select Clients → click "Add Record"
2 Enter: {"name":"Acme Corp","contact":"Jane Smith","email":"jane@acme.com","phone":"+2348000000001"} → Create
3 Add a second record: {"name":"Globex","contact":"John Doe","email":"john@globex.com"}
4 Edit the first record: hover → ✏️ → change phone → Update
5 Delete the second record: hover → 🗑 → confirm
  • 2 records created
  • Phone number updated successfully
  • 1 record deleted
  • 1 record remaining

Exercise 3.3 — Search & Copy

🎯 Goal: Search records and copy data.

1 Use the search bar above records to find "Acme"
2 Hover over the record and click 📋 to copy the JSON data
3 Paste into a text editor to verify the copied data is correct
  • Search filters correctly
  • Copied JSON is valid and complete

MODULE 4: User & Role Management

Scenario: A team member changes roles and a new hire needs access. You'll update user roles, reassign companies, and deactivate departed users.

Exercise 4.1 — Promote a User

🎯 Goal: Promote "Team Member A" to company_admin.

1 Go to Users
2 Find Team Member A
3 Hover → ✏️ → change role to company_admin → 💾 Save
  • Role badge updates to company_admin color

Exercise 4.2 — Reassign Company

🎯 Goal: Move "Viewer Account" to Beta Division.

1 Find Viewer Account
2 Hover → ✏️ → select Beta Division → 💾 Save
  • Company column shows Beta Division

Exercise 4.3 — Deactivate a User

🎯 Goal: Deactivate "Viewer Account" and verify they can't log in.

1 Find Viewer Account
2 Hover → 🗑 → confirm deactivation
3 Try logging in with viewer credentials — should fail
  • User removed from active list
  • Login rejected for deactivated user

MODULE 5: Quota Management

Scenario: Alpha Division is growing fast and needs more storage. You need to increase their quota while monitoring overall usage.

Exercise 5.1 — Adjust Quotas

🎯 Goal: Increase Alpha's quota and verify the change.

1 Go to Settings → Storage Quota
2 Increase Alpha Division to 15 GB → Set
3 Verify the organization usage bar is still accurate
  • Alpha quota shows 15 GB
  • Total org quota (20 GB) unchanged

Exercise 5.2 — Understand the Usage Bar

🎯 Goal: Upload files until the usage bar changes color.

1 Upload files and watch the usage bar
2 Note when the bar turns from blue → amber (>70%)
3 Note when the bar turns from amber → red (>90%)
  • Usage percentage updates after each upload
  • Color changes at correct thresholds

MODULE 6: Security & Audit

Scenario: You're responsible for data security. You need to understand the security features and verify they're active.

Exercise 6.1 — Verify Encryption

🎯 Goal: Confirm files are encrypted at rest.

1 Upload a small text file
2 Note the original size vs encrypted size (e.g., 18 B → 82 B)
3 Download the file and verify contents are identical
  • Encrypted size is larger than original
  • Decrypted download matches original

Exercise 6.2 — Review Security Settings

🎯 Goal: Check that all security features are active.

1 Go to Settings
2 In the Security section, verify:
  • Encryption at Rest: ✅ Active (AES-256-GCM)
  • JWT Authentication: ✅ Active (24h tokens)

MODULE 7: Troubleshooting

ProblemSolution
Can't log inCheck caps lock. Passwords are case-sensitive. Use "Forgot password" or contact admin.
"Not found" error on loginHard refresh (Ctrl+Shift+R). If persists, check internet connection.
Upload blocked — quota exceededGo to Settings → increase quota, or delete unused files to free space.
Company selector not showingYou need companies created first. Go to Companies → Add Company.
Can't edit users or settingsYou need org_admin or superadmin role. Contact your admin.
Files missing after switching companiesFiles are scoped to companies. Switch to "All Companies" to see everything.
Record JSON won't saveEnsure your JSON is valid — check for missing commas, quotes, or braces.

Completion Checklist

After completing all modules, you should be able to:

  • Create and manage companies
  • Add, edit, and deactivate users with proper roles
  • Upload, organize, search, download, and delete files
  • Use folders, tags, and company selector for data isolation
  • Create data tables and perform full CRUD on records
  • Set and adjust storage quotas at org and company levels
  • Monitor storage usage with the usage bar
  • Verify encryption and security features
  • Troubleshoot common issues
