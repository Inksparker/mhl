1. Getting Started

Accessing OrgVault

Open your browser and go to: https://storageapp.boosterappsolutions.com

Creating an Account

1 On the login page, click "Don't have an account? Create one"
2 Enter your Full Name, Organization Name, Email, and Password (min. 12 characters)
3 Click "Create Account" — you'll be logged in automatically
Note: The first person to register with an organization name becomes the Organization Admin.

Logging In

1 Enter your Email and Password
2 Click "Sign In"

Sessions last 24 hours. Log out via the "Sign Out" button at the bottom of the sidebar.

2. Dashboard

The Dashboard is your home screen, showing a real-time overview of your organization's storage.

Stats Cards

CardMeaning
Total FilesNumber of files across your org or selected company
FoldersNumber of organizational folders
Storage UsedTotal space consumed (auto-formatted: B → KB → MB → GB)
Synced to CloudFiles backed up to cloud storage

Recent Files

Shows your 5 most recent uploads. Click "View all →" to go to the Files page.

Company Selector

In the top-right header, use the company dropdown to switch between company views. Select "All Companies" to see everything, or pick a specific company to scope all views.

3. File Management

Access via Files in the left sidebar.

Uploading Files

1 Drag & Drop files onto the dashed zone, or click to browse
2 Optionally assign a folder (e.g., invoices/2024) and tags (comma-separated)
3 Files are encrypted with AES-256-GCM before storage
Limits: 500 MB max per file. Upload blocked if storage quota is exceeded.

Folder Navigation

Click a folder card to filter files within it. Use the breadcrumb trail (Root › invoices › 2024) to navigate back.

Tag Filtering

Click any tag on a file to filter the list by that tag. Remove the filter by clicking ✕ on the active tag pill.

Search

Use the search bar to find files by name. Results update as you type.

Download & Delete

Hover over a file row to reveal action buttons: ⬇ Download (decrypted) and 🗑 Delete (soft-delete, recoverable).

4. Data Records

Store structured data in custom tables. Access via Data Records in the sidebar.

Creating a Table

1 Click "New Table"
2 Enter a name (e.g., Contacts, Invoices)
3 Press Enter or click "Create"

Working with Records

Add: Select a table → click "Add Record" → enter JSON data → Create

Edit: Hover a record → ✏️ → modify JSON → Update

Delete: Hover a record → 🗑 → confirm

Copy: Use the 📋 button to copy record IDs or JSON data

Example record: {"name": "John Doe", "email": "john@example.com", "phone": "+234 800 000 0000"}

5. Companies

Companies are sub-tenants within your organization for data isolation. Access via Companies in the sidebar.

Adding a Company

1 Click "Add Company"
2 Enter the company name
3 Click "Create"

Once created, you can assign users to this company, set storage quotas, and files will be scoped.

6. User Management

Access via Users in the sidebar. Available to org_admin and superadmin roles only.

Adding Users

1 Click "Add User"
2 Fill in name, email, password
3 Select a role and optionally assign to a company
4 Click "Create User"

Editing Users

Hover a user row → click ✏️ → change their role or company inline → click 💾 to save.

Deactivating Users

Hover a user row → click 🗑 → confirm. They can no longer log in, but their data is preserved.

7. Storage Quotas

Access via Settings → Storage Quota section.

Organization Quota

A colored usage bar shows current consumption. Enter a value in GB and click "Set Quota". Set to 0 for unlimited.

Company Quotas

Each company can have its own limit. Enter GB per company → click "Set". Companies with no limit set have unlimited storage (capped only by the org quota).

Who controls quotas: Only org_admin and superadmin can set quotas. Company admins and members can view usage but can't change limits.

9. Security

  • Encryption: AES-256-GCM at rest, unique per-file keys via PBKDF2
  • Passwords: Argon2id hashing — industry standard
  • Sessions: 24h access tokens + 7d rotating refresh tokens
  • Rate Limiting: Brute-force protection on login endpoints
  • Audit Logging: All mutations logged with user ID, IP, and timestamp
  • Data Isolation: Org-scoped queries, company-level filtering
