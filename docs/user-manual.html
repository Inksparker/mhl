1. Getting Started

Accessing OrgVault

Open your browser and go to your OrgVault URL. You'll see the login page with the OrgVault shield logo on the left and the sign-in form on the right.

Creating an Account

1 On the login page, click "Don't have an account? Create one"
2 Fill in your Full Name, Organization Name, Email, and Password (minimum 12 characters)
3 Click "Create Account"
4 You'll be automatically logged in and taken to the Dashboard
Tip: The first person to register becomes the Organization Admin. A superadmin can promote you to additional roles later.

Logging In

1 Enter your Email and Password
2 Click "Sign In"

You'll be taken directly to your Dashboard. Your session lasts 24 hours before you need to log in again.

Logging Out

Click "Sign Out" at the bottom of the left sidebar.

3. File Management

The Files page is where you upload, organize, and manage all your documents and files. Access it by clicking Files in the left sidebar.

Uploading Files

There are two ways to upload:

1 Drag & Drop: Drag files from your computer onto the dashed upload zone
2 Browse: Click the "Upload" button or click anywhere in the upload zone to open a file picker
Tip: You can upload multiple files at once. Maximum file size is 500 MB per file. Files are encrypted with AES-256-GCM before storage.

Organizing with Folders

When uploading, you can assign files to a folder. Use folder names like invoices/2024 for nested organization. Click a folder in the folder grid to filter files within it. Use the breadcrumb trail at the top to navigate back.

Tagging Files

Add tags when uploading to categorize files (e.g., invoice, confidential, draft). Click any tag on a file to filter the file list by that tag. Remove the tag filter by clicking the ✕ on the active tag pill.

Searching Files

Use the search bar to find files by name. Search works across your current folder and updates results as you type.

Downloading & Deleting

Hover over a file row to reveal action buttons:

ActionButtonWhat it does
Download⬇Downloads the decrypted file to your computer
Delete🗑Soft-deletes the file (recoverable by admin)
Important: Deleted files are soft-deleted (hidden but retained). Contact your admin for permanent deletion.

4. Data Records

The Data Records page lets you store structured data in custom tables — perfect for contacts, invoices, inventory, or any tabular data. Access it via Data Records in the sidebar.

Creating a Table

1 Click "New Table" at the top right
2 Enter a name (e.g., Contacts, Invoices)
3 Press Enter or click "Create"

Your table appears in the left panel. Click it to view records.

Adding Records

1 Select a table from the left panel
2 Click "Add Record"
3 Enter JSON data in the editor:
{
  "name": "John Doe",
  "email": "john@example.com",
  "phone": "+234 800 000 0000"
}
4 Click "Create"
Tip: Records are stored as flexible JSON — each record can have different fields. Use the Copy button to duplicate JSON structure.

Editing Records

Hover over a record and click the ✏️ Edit button. Modify the JSON in the editor and click "Update".

Deleting Records & Tables

Hover over a record and click 🗑 Delete. To delete an entire table, hover over it in the left panel and click the trash icon. This removes all records in that table.

Searching Records

Use the search bar above the record list to filter records by their JSON content.

5. Companies

Organizations can have multiple companies (sub-tenants) to isolate data between departments or subsidiaries. Access via Companies in the sidebar.

Adding a Company

1 Click "Add Company"
2 Enter the company name
3 Press Enter or click "Create"

The company appears in the table. Users can be assigned to companies for data isolation.

8. Security

Encryption

Every file uploaded to OrgVault is encrypted with AES-256-GCM before being written to disk. A unique encryption key is derived for each file using PBKDF2 from a master key, ensuring no two files share the same encryption key.

Authentication

  • Passwords are hashed with Argon2id — the industry standard
  • Access tokens expire after 24 hours
  • Refresh tokens rotate on each use and expire after 7 days
  • Rate limiting protects login endpoints from brute-force attacks

Audit Logging

All mutating operations (uploads, deletes, record changes) are logged with timestamps, user IDs, and IP addresses. Audit logs are immutable and available to admins.

Data Isolation

All database queries are automatically scoped to your organization. Companies provide an additional layer of isolation within your org.

9. Roles & Permissions

RoleBadgePermissions
Superadmin superadmin Full access across all organizations. Can promote/demote users, delete organizations, access all data.
Org Admin org_admin Manage their organization: add companies, view all files/records, manage users within their org.
Company Admin company_admin Manage a specific company: files, records, and users scoped to that company.
