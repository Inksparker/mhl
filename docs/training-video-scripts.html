🎬 OrgVault Training Videos

Script Outlines & Recording Guide

Recording Tips

  • Record at 1920×1080 (1080p) for best quality
  • Use a screen recorder like OBS Studio (free), Loom, or Screenity
  • Speak clearly at a moderate pace — aim for 2-5 minutes per video
  • Show your face in a small corner circle for personal connection
  • Upload finished videos to YouTube (unlisted) or Vimeo
  • Copy the embed URL and add it to the training lesson in the app

1. Welcome to Your Company Vault

⏱ Duration: 2 min | 🎯 Audience: All company users
[SCREEN: OrgVault login page with company branding]
"Welcome to OrgVault — your company's secure storage platform. In this video, I'll show you what OrgVault is and how it keeps your data safe."
[SCREEN: Transition to dashboard with stats cards]
"OrgVault is a hybrid secure storage platform. That means your files are encrypted before they're stored. Only people in your company can access them."
[SCREEN: Show encryption badge in Settings → Security]
"Every file is protected with AES-256-GCM encryption — the same standard used by banks and governments."
[SCREEN: Company selector dropdown]
"If your organization has multiple companies, use this dropdown to switch between them. You'll only see the files and data for the company you're viewing."
"Let's get started with the basics."

2. Navigating Your Workspace

⏱ Duration: 3 min | 🎯 Audience: All company users
[SCREEN: Dashboard view, mouse hovering over sidebar items]
"Let me show you around. The left sidebar is your main navigation."
[Highlight: Dashboard]
"Dashboard shows your company's stats at a glance — how many files you have, storage used, and recent activity."
[Highlight: Files]
"Files is where you upload, organize, and find your documents."
[Highlight: Data Records]
"Data Records lets you work with structured data in tables — like contacts, invoices, or inventory."
[Highlight: Company Training]
"And Company Training is where you are now — your step-by-step guide to mastering OrgVault."

3. Uploading Your First Files

⏱ Duration: 5 min | 🎯 Audience: Members & Company Admins
[SCREEN: Files page with empty state]
"Let's upload some files. Go to the Files page. You'll see a dashed upload zone."
[SCREEN: Drag a file from desktop into the upload zone]
"You can drag and drop files directly from your computer, or click anywhere in the zone to browse."
[SCREEN: Type folder name and tags during upload]
"Before uploading, you can organize with folders and tags. Type a folder name like 'invoices' or 'reports/2024' for nested folders."
"Tags help categorize files. Add comma-separated tags like 'important, draft, client-x'."
[SCREEN: File appears in table with tags and folder]
"Your file is now encrypted and stored. Notice the size — the encrypted version is slightly larger, which confirms encryption is working."

4. Organizing with Folders & Tags

⏱ Duration: 4 min | 🎯 Audience: All users
[SCREEN: Files page with multiple folders in the grid]
"Good organization makes files easy to find. Click any folder card to see files inside it."
[SCREEN: Click "invoices" folder — files filter]
"Use the breadcrumb trail at the top to navigate back. Click 'Root' to return to the main view."
[SCREEN: Click a tag on a file]
"Tags are clickable filters. Click any tag to see all files with that tag. Click the X to clear the filter."

5. Finding Files Fast

⏱ Duration: 3 min | 🎯 Audience: All users
[SCREEN: Files page — type in search bar]
"Use the search bar to find files by name. Results update as you type."
[SCREEN: Combine search with tag filter]
"Combine search with tag filters for precise results — search for 'invoice' and filter by the '2024' tag."
"If you can't find what you're looking for, clear all filters and try different search terms."

6. Downloading & Deleting Files

⏱ Duration: 2 min | 🎯 Audience: All users
[SCREEN: Hover over file row — action buttons appear]
"Hover over any file to reveal action buttons. Click the download icon to get your file — it's automatically decrypted."
[SCREEN: Click delete — confirmation dialog]
"To delete, click the trash icon and confirm. Deleting files frees up storage for your company."
"Remember — deleted files are soft-deleted. Contact your admin if you need something recovered."

7. Working with Data Records

⏱ Duration: 5 min | 🎯 Audience: Members & Company Admins
[SCREEN: Data Records page — select a table]
"Data Records lets you store structured information. Think of it as a flexible database."
[SCREEN: Click Add Record — JSON editor appears]
"Click Add Record and enter your data in JSON format. Don't worry — it's simpler than it sounds."
[SCREEN: Type example JSON and click Create]
{ "name": "Acme Corp", "contact": "Jane Smith", "email": "jane@acme.com" }
"Each record can have different fields. Use the copy button to duplicate records as templates."
"Hover to edit or delete records. Use the search bar to find specific entries."

8. Understanding Storage Limits

⏱ Duration: 2 min | 🎯 Audience: All users
[SCREEN: Dashboard — point to storage used stat]
"Your company has a storage limit set by your administrator. Check your Dashboard to see how much you're using."
[SCREEN: Settings → Storage Quota — usage bar]
"The usage bar changes color: blue means healthy, amber means getting full, red means almost full."
"If you hit the limit, uploads will be blocked. Delete old or unnecessary files to free up space."

9. Keeping Data Secure

⏱ Duration: 2 min | 🎯 Audience: All users
[SCREEN: Settings → Security section]
"Security is built into every part of OrgVault. Let me show you how."
[Highlight: Encryption at Rest — Active]
"AES-256-GCM encryption protects every file. Even if someone accessed the storage directly, they couldn't read your files."
[Highlight: JWT Authentication — Active]
"Your session lasts 24 hours with automatic token rotation. Never share your password."
"Always log out when using shared computers. Your data is only as secure as your password."
